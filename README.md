# पं. श्री चैतन्य कुमार चतुर्वेदी शास्त्री जी — वेबसाइट

यह एक static, responsive multi-page website है। किसी build step या package install की आवश्यकता नहीं है। `index.html` को सीधे browser में खोलें या `outputs` folder को किसी static hosting provider पर publish करें.

## Pages

- `index.html` — मुखपृष्ठ और सेवाओं का परिचय
- `about.html` — परिचय एवं सेवा क्षेत्र
- `panchang.html` — दिनांक दिखाने वाला पंचांग पृष्ठ; तिथि, नक्षत्र और मुहूर्त स्थानीय पंचांग से सत्यापित किए जाने चाहिए
- `pooja.html` — सामान्य गणेश पूजन, हवन और गृह प्रवेश मार्गदर्शिका

## प्रकाशित करने से पहले

- उपलब्ध भाषाएँ और वास्तविक चित्र जोड़ें।
- पंचांग में सटीक तिथि, नक्षत्र, सूर्योदय और मुहूर्त दिखाने के लिए किसी विश्वसनीय स्थान-आधारित पंचांग स्रोत/गणना को जोड़ें। अभी पृष्ठ तारीख दिखाता है और स्पष्ट करता है कि शेष विवरण स्थान के अनुसार सत्यापित हों।
- पूजा विधियाँ सामान्य जानकारी हैं; अपने कुलाचार और अनुष्ठान के अनुसार आचार्य से पुष्टि करें।
